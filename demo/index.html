IE Page Transitions

Bringing back Internet Explorer’s Page Transitions thanks to the View Transition API

ie-page-transitions is a small CSS + JS library that brings back Microsoft Internet Explorer’s proprietary Interpage Transitions to modern browsers, powered by the View Transition API.

Internet Explorer’s Page Transitions

Microsoft Internet Explorer 4.0 and above featured a proprietary feature called Interpage Transitions. It allowed authors to specify a transition effect to apply to the entire browser window as a web page was loaded or exited.

The feature worked best as of Internet Explorer 5.5—which had a richer variety of optimized filters—before eventually being deprecated in Internet Explorer 9.

Transitions were specified using a <meta> tag in the <head> of a web page, hooked into one of four events: Page-Enter, Page-Exit, Site-Enter, and Site-Exit:

<meta http-equiv="Page-Enter" content="progid:DXImageTransform.Microsoft.Blinds(Duration=4)" />
<meta http-equiv="Page-Exit" content="progid:DXImageTransform.Microsoft.Slide(Duration=2.500,slidestyle='HIDE')" />

The RevealTrans Filter

Page Transitions also came with a convenient shorthand: the DXImageTransform.Microsoft.RevealTrans filter, which offered 23 predefined transitions mirrored from the slide transitions found in Microsoft PowerPoint.

Using one of these predefined effects was as easy as referring to its number—ranging from 0 to 22—in the Transition property (or 23 to randomly select one of the 23 effects):

<meta http-equiv="Page-Enter" content="revealTrans(Duration=0.5,Transition=7)">

Under the hood, revealTrans(Transition=7)—a vertical wipe from right to left—mapped to a DXImageTransform.Microsoft.Blinds(direction='left', bands=1) effect.

How This Library Works

ie-page-transitions reads the original <meta http-equiv="Page-Enter"> and <meta http-equiv="Page-Exit"> tags from your HTML document and translates them into Selective View Transitions with Active Types. The accompanying CSS stylesheet then animates ::view-transition-old(root) and ::view-transition-new(root) using modern CSS (such as clip-path, mask-image, and @keyframes).

Combining Exit and Entry Transitions

In Internet Explorer it was not possible for one page to run an exit transition and the next page to run an entry transition—having both caused a conflict resulting in no transition happening at all. This library lifts that limitation: when both an exit and an entry effect are configured, they run sequentially.

Effect Configuration & Custom Properties

Just like in IE, effects are configured via the <meta> tag:

  • Set http-equiv to Page-Enter or Page-Exit.
  • Set Duration in seconds (supported values: 0.5, 1.0, 1.5, and 2.0).
  • Set Transition to an integer from 0 to 22, or 23 for a random effect.

Several effects can also be fine-tuned via CSS Custom Properties on :root:

  • --page-transitions-backdrop-color: Backdrop color of ::view-transition between sequential exit and entry effects (default: transparent).
  • --page-transitions-blinds-bands: Number of bands for Blinds effects 8 and 9 (default: 6).
  • --page-transitions-checkerboard-columns & --page-transitions-checkerboard-rows: Grid size for Checkerboard effects 10 and 11 (default: 10).
  • --page-transitions-random-dissolve-size: Pixel size for Random Dissolve effect 12 (default: 4px).
  • --page-transitions-random-bars-size: Bar thickness for Random Bars effects 21 and 22 (default: 4px).

Usage

Install via NPM (npm install ie-page-transitions) or load directly from a CDN such as unpkg or jsDelivr.

MPA (Cross-Document View Transitions)

<!-- 1. Enable Cross-Document View Transitions -->
<style>
    @view-transition {
        navigation: auto;
    }
</style>

<!-- 2. Include stylesheet and render-blocking MPA script -->
<link rel="stylesheet" href="https://unpkg.com/ie-page-transitions/ie-page-transitions.css">
<script src="https://unpkg.com/ie-page-transitions/ie-page-transitions.mpa.js" type="module" blocking="render"></script>

<!-- 3. Configure your desired effect(s) -->
<meta http-equiv="Page-Enter" content="revealTrans(Duration=0.5,Transition=23)">
<meta http-equiv="Page-Exit" content="revealTrans(Duration=0.5,Transition=23)">

SPA (Same-Document View Transitions)

<link rel="stylesheet" href="https://unpkg.com/ie-page-transitions/ie-page-transitions.css">
<meta http-equiv="Page-Enter" content="revealTrans(Duration=0.5,Transition=23)">
<meta http-equiv="Page-Exit" content="revealTrans(Duration=0.5,Transition=23)">

<script type="module">
    import { startViewTransition } from 'https://unpkg.com/ie-page-transitions/ie-page-transitions.spa.js';

    $button.addEventListener('click', () => {
        startViewTransition(updateTheDOMSomehow);
    });
</script>

Browser Support

Requires a browser with built-in Page Transitions support or support for the View Transition API + Selective View Transitions with Active Types:

  • SPA: Chrome 125+, Safari 18.2+
  • MPA: Internet Explorer 5.5–8.0 (built-in), Chrome 126+, Safari 18.2+ (buggy)

In browsers without View Transitions support, no effects will run and the presence of ie-page-transitions.css won’t negatively affect the page.
