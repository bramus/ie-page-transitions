IE Page Transitions (SPA)

Bringing back Internet Explorer’s Page Transitions thanks to the View Transition API

← To Index

1. Surfing the 90s Web

Back in 1997, Microsoft Internet Explorer 4.0 introduced Interpage Transitions—letting webmasters add dramatic PowerPoint-style transitions between pages with a single <meta> tag.

Whether you wanted a dramatic circle iris or a classic vertical wipe, every link click became a miniature theatrical event across the Information Superhighway.

2. Coastal Horizons & Scenic Wipes

With the modern View Transition API and Selective View Transitions with Active Types, we can recreate all 23 classic RevealTrans effects purely in CSS.

Unlike Internet Explorer—where setting both an exit and an entry effect caused a conflict—this library smoothly chains your exit and entry transitions one after the other.

3. Exploring the Digital Frontier

From Box in (0) and Circle out (3) to Random dissolve (12) and Strips right up (20), each effect animates ::view-transition-old(root) and ::view-transition-new(root).

Use the floating control bar below to pick any combination of Exit and Entry effects and hit Go! to cycle to the next view.

4. 23 PowerPoint-Inspired Filters

Fine-tune effects like Blinds, Checkerboard, Random Dissolve, and Random Bars using CSS Custom Properties such as --page-transitions-blinds-bands and --page-transitions-checkerboard-columns.
